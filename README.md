# 🌿 AURORA

**AURORA (Adaptive Unified Research, Organization, and Research Assistant)** is a custom Python desktop assistant designed to help organize creative projects, tasks, and workflows through a personalized graphical interface.

## ✨ About

AURORA is a personal productivity and organization application built from the ground up in Python. The project combines software development with creative workflow management, providing a structured space for managing projects, tasks, memories, and future assistant capabilities.

## Data Privacy

AURORA stores user information locally using JSON files.
Example data is included for demonstration purposes.
Personal user data files are excluded from this repository.

## 🚀 Features

- Custom desktop graphical interface
- Project archive and management system
- Task tracking and organization
- Memory and journal management
- Modular application structure
- JSON-based data storage
- Custom themed user experience

## 🛠️ Technologies Used

- Python
- CustomTkinter
- Object-Oriented Programming
- JSON Data Management
- Desktop Application Development
